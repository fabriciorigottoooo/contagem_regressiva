# ⏳ Contagem Regressiva

Um site interativo e elegante que exibe uma contagem regressiva até um evento especial, com efeitos visuais impressionantes e funcionalidades adicionais.

## ✨ Características

- **Contador em Tempo Real**: Exibe os dias, horas, minutos e segundos restantes até o evento
- **Efeitos Visuais Deslumbrantes**: 
  - Animações de "choque" e brilho ao passar o mouse
  - Transições suaves e fluidas
  - Fundo com tema escuro elegante
- **Modo "Ana Banana"**: Botão especial com tema personalizado (canto inferior direito)
- **Mapa Interativo**: Visualize a localização do evento
- **Lista de Ausentes**: Acompanhe quem não poderá comparecer
- **Design Responsivo**: Funciona perfeitamente em desktop, tablet e celular

## 📁 Estrutura do Projeto

```
├── index.html       # Arquivo principal com HTML, CSS e JavaScript
├── audio/          # Pasta com arquivos de áudio (se houver)
└── README.md       # Este arquivo
```

## 🚀 Como Usar

1. Abra o arquivo `index.html` em seu navegador
2. Veja a contagem regressiva em tempo real
3. Passe o mouse sobre os números para ver o efeito especial
4. Clique no botão "Mapa" para ver a localização do evento
5. Clique em "Ausentes" para ver quem não comparecerá
6. Explore o Modo Ana Banana no canto inferior direito!

## 🎨 Personalização

Para modificar a data do evento, localize a variável de data no código JavaScript dentro do `index.html` e altere-a conforme necessário.
